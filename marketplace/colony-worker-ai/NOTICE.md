# Provenance and release boundary

The examples in this folder were written as a standalone adaptation of the original HelioConde/TILLFOLK worker assignment behavior (src/worker-allocation.js, docs/IA_ALOCACAO_TAREFAS.md). The implementation is separate from the game and deliberately excludes third-party SKILL.md content and all Sprout Lands licensed assets.
