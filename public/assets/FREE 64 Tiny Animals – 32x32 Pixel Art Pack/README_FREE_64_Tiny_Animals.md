# FREE 64 Tiny Animals – 32x32 Pixel Art Pack

A cute collection of **64 tiny pixel-art animals**, made for cozy games, RPGs, farming games, survival games, adventure games, prototypes, and more.

Every animal is designed at **32x32 pixels** in a clean, readable pixel-art style.

## Included

- 64 unique tiny animals
- 32x32 pixel sprites
- Transparent PNG files
- Individual animal sprites
- Sprite sheet
- Clean, consistent pixel-art style
- Ready to use in game engines such as Godot, Unity, GameMaker, Construct, RPG Maker, and more
