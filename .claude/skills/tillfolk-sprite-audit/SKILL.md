# tillfolk-sprite-audit

Aplicação: TILLFOLK HTML5 Canvas + jogo de sobrevivência de colônia.

## Passos
1. Encontre imagem local e licença. 2. Abra atlas e calcule o frame real sem suposições. 3. Registre (x,y,w,h) numa tabela de teste. 4. Mostre screenshot do item isolado e na Work Station/cena. 5. Verifique pixelated, escala inteira, transparência, orientação direita/esquerda. 6. Nunca use pacote premium para treinar IA, nem copie imagens premium a locais não autorizados. 7. Teste navegador e GitHub Pages.

## Critério de conclusão
Código/teste/screenshot coerentes com GDD, nada inventado e save preservado.
