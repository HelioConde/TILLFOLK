# tillfolk-image-to-code

Aplicação: TILLFOLK HTML5 Canvas + jogo de sobrevivência de colônia.

## Passos
1. Peça/identifique screenshot de entrada e elementos reais no DOM/canvas. 2. Faça análise de posição, escala, cores e hierarquia em vez de inventar telas. 3. Reutilize sprites existentes e a estrutura de DESIGN.md. 4. Implemente em CSS/Canvas e compare screenshot real nos viewports originais. 5. A skill externa image-to-code pode precisar de modelo com geração de imagem, mas não é requisito: use análise e programação quando não houver gerador. 6. Respeite licença dos assets e não treine modelo com Sprout Lands.

## Critério de conclusão
Código/teste/screenshot coerentes com GDD, nada inventado e save preservado.
